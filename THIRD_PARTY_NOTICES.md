# Avisos de componentes de terceros

## Eglantine (motor de emulación)

Este paquete incorpora, sin modificar, el motor de emulación **Eglantine** para Windows x64.

- Proyecto: https://github.com/Eglantine-Community/Eglantine
- Versión empaquetada: `v0.1.0-rc3`
- Licencia declarada por el proyecto: GPL-3.0-or-later. El repositorio conserva además avisos de componentes heredados con licencias propias.
- Código fuente correspondiente: se incluye en `licenses/Eglantine-source-v0.1.0-rc3.zip` dentro del paquete publicado.
- Binario oficial de origen: https://github.com/Eglantine-Community/Eglantine/releases/tag/v0.1.0-rc3

El motor se ejecuta como un proceso independiente. El lanzador de este repositorio no contiene el código interno del emulador ni modifica sus claves, firmware o archivos de juegos. Consulta los avisos de licencia del código fuente incluido para conocer las condiciones completas aplicables a Eglantine y sus dependencias.

## Archivos de juegos, firmware y claves

Este proyecto no distribuye juegos comerciales, firmware de consola ni claves de descifrado. El usuario debe aportar sus propios archivos y tener derecho a utilizarlos. No se incluye ninguna función para descargar copias no autorizadas ni para eludir protecciones.
